## 2. Top 10이 사용하는 4대 핵심 구조 심층 분석

### (1) 제목(Title) 작명 패턴 분석
- **발견 1: 극도의 키워드 집중**: 상위 10개 중 8개가 `AI 챗봇`, `ChatGPT`, `RAG`, `사내문서`, `카카오톡` 단어를 조합함.
- **발견 2: 3위 아이코AI의 승리 카피**: `"출처까지 보여주는 거짓 없는 사내문서 AI 챗봇"` ➔ 고객들이 가장 두려워하는 **환각(거짓말) 공포**를 역발상으로 찔러 단 6개 리뷰만으로 3위 점유.
- **발견 3: 5위 Yerdy의 채널 명시**: `"웹사이트/카카오채널 챗봇 맞춤 제작"` ➔ 챗봇을 어디에 설치하는지(웹사이트 위젯, 카톡) 채널을 명시하여 직관성 확보.

### (2) 패키지 가격 및 티어링 구조 분석
- **STANDARD (5만 ~ 19만 원)**: '문턱 낮추기(Entry Hook)'. 
  - 버튼식 기본 응답 or 문서 30장 기본 RAG. 관리자 대시보드 없이 납품하여 의뢰인 결제 허들을 최소화함.
- **DELUXE (59만 ~ 99만 원)**: '실제 결제되는 스윗스팟(Cash Cow)'. 
  - 사내 PDF/Excel 100~300장 RAG 학습 + 출처 표기 + 관리자 페이지(문서 추가/삭제) + 카카오톡 or 웹 위젯 연동.
- **PREMIUM (149만 ~ 249만 원+)**: '고마진 B2B 엔터프라이즈'. 
  - 기업 사내 DB 연동 + 외부 유출 없는 온프레미스/로컬 모델 + 음성 인터랙션 지원 + 1개월 유지보수.

### (3) 서비스 제공 절차 분석 (왜 이렇게 구성했는가?)
- **공통 5단계 공식**: `무료 사전상담 ➔ 견적/범위 확정 ➔ 중간 테스트 시연(필수) ➔ 최종 연동/배포 ➔ 1개월 무상 하자보수`
- **심리적/실무적 이유**:
  - 챗봇은 일반 프로그램과 달리 "엉뚱한 답변을 하면 어쩌지?"라는 의구심이 큼.
  - 상위 업체들은 예외 없이 **'중간 테스트 시연'** 단계를 넣어 고객이 실제 질문을 던져보고 만족했을 때 최종 배포를 진행함으로써 **클레임과 환불을 0%로 통제**함.

### (4) 의뢰인 준비 사항 분석 (왜 이렇게 구성했는가?)
- **공통 4대 요구사항**:
  1. 챗봇 활용 목적 (CS 고객응대 / 사내문서 검색 / 이벤트 안내)
  2. 학습 데이터 (회사소개서, PDF, FAQ 엑셀 등)
  3. 설치 환경 (웹사이트 우측 하단 위젯 / 카카오톡 채널)
  4. OpenAI API Key (발급 링크 제공 및 대행 안내)
- **심리적/실무적 이유**:
  - "문서 정리가 안 되어 있어도 괜찮으니 상담 시 말씀해 달라"는 문구를 반드시 넣어 **비전공자의 이탈을 방지**.
  - API Key는 의뢰인 카드로 결제하게 하여 **개발자의 월 서버 유지비 부담을 0원화**.

   - 박준형: 키워드 정확 매칭 가중치(2.0/1.0) + 벡터 거리 결합 ➔ 출처 100% 명시, 환각 0%

2. '데이터 외부 유출 0%' 온프레미스/로컬 경량 모델 지원 (Llama 1B SFT 자산)
   - 경쟁자: 무조건 OpenAI 클라우드로 사내 문서를 전송해야 함 (대기업/공공기관 도입 불가)
   - 박준형: 사내 PC에서 100% 로컬 구동 가능한 경량 모델 옵션 제공 (사내 기밀 유출 0%)

3. 음성 대화 챗봇 확장성 (Whisper STT + MeloTTS 자산)
   - 경쟁자: 텍스트 채팅만 가능
   - 박준형: 텍스트뿐만 아니라 음성으로 묻고 음성으로 대답하는 멀티모달 확장 가능

## 🔥 타 외주업체와 완전히 다른 3대 핵심 기술력

### 1. 환각(거짓말) 0% 제어 — 하이브리드 RAG 가중치 엔진
단순히 유사도만 측정하는 시중의 챗봇은 엉뚱한 답변을 지어냅니다.  
본 서비스는 **'키워드 정밀 매칭'과 '문맥 벡터 검색'을 결합한 독자적 하이브리드 가중치 알고리즘**을 적용하여, **답변과 함께 반드시 [출처 문서 및 페이지]를 함께 표기**합니다.

### 2. 회사 기밀 유출 0% 보장 — 사내 로컬 구동 옵션 지원
보안이 엄격한 기업을 위해, OpenAI 서버로 데이터를 보내지 않고 사내 PC/내부망에서 100% 독립 실행되는 **경량 오픈소스 LLM(Llama 등) 온프레미스 구축**이 가능합니다.

### 3. 초고속 실시간 스트리밍 & 직관적 관리자 UI
답변이 나올 때까지 멈춰 있는 답답한 챗봇이 아닙니다.  
ChatGPT처럼 글자가 실시간으로 타이핑되는 비동기 스트리밍을 제공하며, 비전공자도 마우스 클릭 몇 번으로 문서를 추가/수정할 수 있는 관리자 화면을 함께 납품합니다.
