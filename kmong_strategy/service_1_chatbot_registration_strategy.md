## 4. 서비스 제공 절차 (단계별 프로세스 및 분쟁 방지 설계)

```text
1단계: 1:1 사전 상담 (요구사항 및 학습 문서 무료 사전 검토)
2단계: 견적 확정 및 크몽 안전 결제
3단계: 코어 챗봇 엔진 개발 및 문서 데이터 임베딩
4단계: 테스트 링크 시연 (중간 검수: 의뢰인이 직접 대화하며 품질 확인)
5단계: 카카오톡 채널 또는 웹 위젯 최종 배포 및 관리자 가이드 전달
6단계: 1개월 무상 하자보수 지원
```

### [분쟁 방지 설계 이유]
- AI 챗봇 외주에서 발생하는 환불 분쟁의 90%는 "내가 생각했던 답변 톤이 아니다" 또는 "엉뚱한 답을 한다"입니다.
- 따라서 납품 전에 **'4단계: 테스트 링크 시연'**을 의무화하여 의뢰인이 직접 질문을 던져보고 답변 정확도를 승인한 후 최종 배포를 진행하도록 설계했습니다.

## 5. 의뢰인 준비 사항 및 사전 고지

```text
1. 챗봇이 답변해야 할 데이터 파일 (FAQ 엑셀, 매뉴얼 PDF, 회사 소개서 등)
2. 챗봇을 연결할 대상 플랫폼 계정
   - 카카오톡 연동 시: 카카오 비즈니스 관리자 권한
   - 웹사이트 위젯 연동 시: 홈페이지 관리자 권한 또는 개발자 연락처
3. 테스트용 대표 질문 및 정답 예시 5~10가지
4. OpenAI API Key (발급 방법을 모르실 경우 원격으로 세팅 지원)
```

### [책임 분리 설계 이유]
- OpenAI API 종량제 비용을 의뢰인 본인 카드로 등록하게 하여 개발자의 서버 유지비용을 0원화합니다.
- 카카오 계정 소유권을 의뢰인이 직접 보유하게 하여 플랫폼 제재나 정책 변경 시 판매자의 법적 책임을 분리합니다.

## 7. 크몽 등록용 완성형 상세페이지 본문 (복사-붙여넣기용)

```markdown
# 💬 ChatGPT 연동 사내문서/상담 맞춤 AI 챗봇 제작

**"매일 반복되는 고객 문의에 지치셨나요?"**  
**"사내 규정집, 매뉴얼을 찾아 헤매는 시간을 줄이고 싶으신가요?"**

단순한 룰 기반 챗봇이 아닌, **고객사의 실제 문서(PDF, Excel, Word)를 학습하고 정확한 출처까지 표기하는 똑똑한 AI 챗봇**을 구축해 드립니다.

인공지능 소프트웨어 전공 수석 졸업 엔지니어가 직접 설계하여, 거짓 답변(할루시네이션) 없는 안정적인 맞춤형 챗봇을 약속드립니다.

---

### 📌 이런 분들께 강력히 추천합니다!

- 쇼핑몰/병원/학원 등 24시간 반복 CS 상담을 자동화하고 싶으신 대표님
- 사내 취업규칙, 제품 매뉴얼, 기술 문서를 빠르게 검색해야 하는 기업 임직원
- 웹사이트 우측 하단에 코드 한 줄로 깔끔한 챗봇 위젯을 띄우고 싶으신 분
- 고객 접근성이 가장 좋은 카카오톡 채널에 챗봇을 연결하고 싶으신 분

---

### 🚀 본 서비스만의 핵심 차별점 3가지

#### 1. 100% 출처 표기로 거짓 없는 답변 (RAG 기술)
챗봇이 아무 말이나 지어내지 않습니다. 등록해주신 문서 내에서만 답변하며, **"어느 문서, 몇 페이지를 참고했는지"** 출처를 명확히 제시합니다.

#### 2. 편리한 연동 방식 (카카오톡 or 웹사이트 1줄 코드)
- **카카오톡 채널 연동**: 24시간 고객 카톡방에서 즉시 자동 상담.
- **홈페이지 위젯 연동**: 제공해드리는 스크립트 코드 1줄만 붙여넣으면 홈페이지 우측 하단에 챗봇 아이콘이 생성됩니다.

#### 3. 직관적인 관리자 페이지 제공
새로운 매뉴얼이나 공지사항이 생기셨나요?  
개발자를 다시 부를 필요 없이, 관리자 화면에서 파일만 업로드하시면 챗봇이 즉시 새로운 지식을 학습합니다.

---

### 📦 패키지별 상세 안내

#### [STANDARD] 스타터 챗봇 (99,000원 / 작업 3일 / 수정 1회)
- **대상**: 가벼운 기본 상담이나 챗봇 도입 효과를 먼저 검증해보고 싶은 분
- **제공 범위**:
  - 기본 ChatGPT API 연동
  - FAQ 및 대표 질의응답 30건 기반 프롬프트 맞춤 세팅
  - 즉시 테스트 가능한 웹 대화 링크 제공

#### [DELUXE] 지식기반(RAG) 맞춤 챗봇 (890,000원 / 작업 10일 / 수정 2회) ★가장 인기
- **대상**: 회사 문서 기반의 전문 상담 및 카카오톡/웹 연동이 필요한 기업
- **제공 범위**:
  - 사내 문서(PDF/DOCX/Excel) 100장+ RAG 임베딩
  - 100% 출처 표기 기능 (문서 근거 확인)
  - 카카오톡 채널 연동 또는 웹사이트 1줄 위젯 삽입
  - 누구나 쉽게 문서를 추가할 수 있는 관리자 페이지 제공

#### [PREMIUM] 엔터프라이즈 맞춤 시스템 (2,290,000원 / 작업 20일 / 수정 3회)
- **대상**: 대용량 DB 연동, 폐쇄망 보안 환경, 또는 음성 연동이 필요한 기관
- **제공 범위**:
  - 사내 DB(MySQL, PostgreSQL 등) 실시간 연동
  - 외부 유출 없는 사내 PC/서버 로컬 LLM 구축 지원 (보안형)
  - 실시간 음성 대화(STT/TTS) 연동 옵션
  - 1개월 무상 유지보수 및 운영 가이드

### 🛠 서비스 진행 절차

1. **사전 문의 및 무료 상담**: 원하시는 기능과 학습시킬 문서(PDF, FAQ)를 확인하고 기술적 구현 가능성을 검토합니다.
2. **결제 및 자료 전달**: 크몽 안전결제 후 안내에 따라 자료를 전달해 주시면 즉시 개발에 착수합니다.
3. **코어 엔진 개발**: 문서 임베딩 및 최적의 답변 프롬프트/RAG 엔진을 구축합니다.
4. **테스트 링크 시연 (중간 점검)**: 의뢰인께서 직접 질문을 입력해보며 답변 정확도를 확인하는 중간 검수를 거칩니다.
5. **최종 배포 및 가이드 전달**: 카카오톡 채널 또는 웹사이트에 연결해 드리고, 사용 매뉴얼을 전달합니다.
6. **사후 관리**: 납품 후 발생하는 오류에 대해 신속하게 무상 보수를 지원합니다.
```
