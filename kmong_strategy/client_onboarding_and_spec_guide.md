## 1. 인프라·서버·도메인·DB 계정 처리 원칙 (외주 분쟁 및 유지비 리스크 0% 공식)

### [철칙] 개발자 개인 카드로 서버/도메인을 절대 결제하지 않는다!
- 서버비, 도메인비, OpenAI API 사용료 등 **모든 인프라 비용은 100% 의뢰인 계정에서 결제**되는 것이 B2B 외주의 업계 표준입니다.
- 개발자가 대신 결제해주면 나중에 고객이 잠적하거나 카드 결제 분쟁이 발생했을 때 고스란히 개발자 빚이 됩니다.

### 실무 유형별 인프라 처리 3가지 방법

| 서비스 형태 | 권장 인프라 구성 | 계정 및 배포 방식 | 난이도 및 위험도 |
| :--- | :--- | :--- | :---: |
| **타입 A: 로컬 실행 프로그램 (가장 추천)** | Python 실행파일(`.exe`) 또는 로컬 Streamlit | 고객 컴퓨터에 AnyDesk(원격)로 원격 설치. **서버/도메인 비용 0원**. | **가장 안전 (리스크 0%)** |
| **타입 B: 클라우드 웹 서비스 (가벼운 웹)** | Vercel / Cloudtype / Render + Supabase | 고객이 해당 플랫폼 무료/유료 가입 후 카드 등록 ➔ 개발자를 팀원으로 초대하거나 AnyDesk로 배포. | **매우 낮음 (월 0~1만 원)** |
| **타입 C: 엔터프라이즈 서버 (중대형)** | AWS / GCP / Naver Cloud Platform | 고객사 계정 생성 가이드 전달 ➔ 고객이 IAM 서브계정(개발자용 제한 권한) 발급 ➔ 배포 후 서브계정 삭제. | **표준적 B2B 방식** |

## 2. 크몽 상세페이지 필수 항목: "서비스 제공 절차" & "의뢰인 준비사항" (소비자 심리학 반영)

### (1) '의뢰인 준비사항' 복사/붙여넣기 문안
> **[의뢰인 준비사항]**  
> **"복잡한 개발 기획서가 없어도 괜찮습니다! 전문 기획은 제가 도와드립니다."**  
> 
> 상담 전 아래 3가지만 편하게 생각나는 대로 알려주시면 됩니다:  
> 1. **해결하고 싶은 문제**: "현재 어떤 수작업이나 비효율을 AI로 줄이고 싶으신가요?"  
> 2. **보유하신 데이터**: 참고할 엑셀 파일, 문서(PDF), 수집할 웹사이트 링크 등  
> 3. **희망 일정 및 예산**: 언제까지 필요하시고 생각하시는 대략적인 예산 범위  
> 
> *(※ API 키 발급, 서버/도메인 계정 생성 등 기술적인 부분은 1:1 원격으로 친절히 세팅 가이드를 드립니다.)*

---

### (2) '서비스 제공 절차' 복사/붙여넣기 문안
> **[서비스 제공 절차 - 투명한 5단계 보장]**  
> 
> 1. **1:1 사전 상담 및 요구사항 진단 (무료)**  
>    - 5문 5답 체크리스트를 통해 원하시는 기능을 명확히 정의하고 실현 가능성을 사전 검증합니다.  
> 2. **견적 확정 및 안전 결제**  
>    - 작업 범위(Scope)와 일정을 상호 합의한 후 크몽 안전 결제를 진행합니다.  
> 3. **중간 시연 및 프로토타입 컨펌 (오차 0%화)**  
>    - 개발 중간 과정에서 핵심 기능 시연 화면(또는 영상)을 공유하여 방향성을 점검합니다.  
> 4. **최종 납품 및 1:1 원격 설치/배포**  
>    - AnyDesk/TeamViewer를 통해 의뢰인 PC 또는 회사 서버에 완벽 구동될 때까지 원격 세팅해 드립니다.  
> 5. **구매 확정 및 30일 무상 하자보수**  
>    - 납품 후 발견되는 버그나 구동 오류에 대해 30일간 100% 무상 AS를 보장합니다.

## 3. 비전공자 고객도 술술 답하는 "5문 5답 요구사항 명세 인터뷰 시트"

고객에게 "기획서나 요구사항 명세서 주세요"라고 하면 이탈률이 90%입니다.  
문의가 오면 아래 템플릿을 그대로 복사해서 메시지로 전송하십시오:

```text
안녕하세요! 문의주셔서 감사합니다.
정확한 견적과 최적의 개발 방식을 빠르게 산출해 드리기 위해 
아래 5가지 항목에 대해 편하게 답변 부탁드립니다. (모르시는 항목은 '모름'으로 남겨주셔도 됩니다!)

[1. 현재 겪고 계신 핵심 문제 / 해결하고 싶은 업무]
  (예: 매일 네이버/구글에서 뉴스 100개를 일일이 복사해서 엑셀에 정리하느라 2시간이 걸립니다.)
  👉 답변: 

[2. 활용할 데이터 원본 및 형태]
  (예: 크롤링할 타깃 웹사이트 URL 주소 / 회사 사내 매뉴얼 PDF 10개 / 엑셀 원본 파일 등)
  👉 답변: 

[3. 최종적으로 받고 싶으신 결과물 형태]
  (예: 엑셀 파일 자동 저장 / 슬랙 or 텔레그램 알림 / 웹 브라우저 대시보드 / 바탕화면 더블클릭 실행 프로그램)
  👉 답변: 

[4. 실행 환경 희망 사항]
  (예: 내 사무실 PC에서 필요할 때만 클릭 실행 / 24시간 클라우드 서버에서 무중단 자동 실행)
  👉 답변: 

[5. 희망 납기일 및 생각하고 계신 예산 범위]
  (예: 2주 이내 / 100만~150만 원 선)
  👉 답변: 

답변 주시면 인공지능 전문 엔지니어가 1시간 이내로 실현 가능성 검토 후 최적의 맞춤 견적을 회신드리겠습니다!
```

## 4. 첫 서비스로 론칭할 추천 1순위 기그: "[데이터 수집 & AI 자동 분석/요약 대시보드]"
- **선정 이유**:
  - 도메인/서버 비용 없이 **로컬 실행파일(.exe) 또는 엑셀/슬랙 자동화**로 납품 가능하여 인프라 분쟁 리스크가 0%입니다.
  - 박준형 개발자의 `국방 기사 자동 크롤링 + klue/bert 분류 + KoBART 요약 + 배치 메모리 제어` 포트폴리오를 100% 재활용할 수 있습니다.
  - 타깃 고객(마케터, 소상공인, 리서처, 기획자)의 시장 수요가 가장 넓고 구매 결정이 빠릅니다.
