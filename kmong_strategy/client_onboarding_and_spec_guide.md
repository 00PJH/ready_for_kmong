## 1. 인프라(서버, 도메인, DB, 배포) 계정 및 비용 실무 해결책

의뢰인에게 웹/시스템을 납품할 때 **"서버 비용과 계정을 어떻게 처리해야 하는가?"**에 대한 업계 표준 3대 공식입니다.

### 공식 1: 로컬 실행형 (Zero-Infra) — 추천도 ★★★★★ (초기 1순위)
- **방식**: 클라우드 서버에 올리지 않고, 의뢰인의 PC/사내 컴퓨터에서 직접 실행되는 방식 (.exe 파일 or 로컬 웹 브라우저 UI)
- **장점**: 
  - 의뢰인 입장: **월 서버 비용 0원**, 외부 유출 걱정 없음
  - 개발자 입장: 계정/도메인/배포 복잡성 0, 납품 후 서버 장애 책임 없음
- **적용 예시**:
  - 뉴스/데이터 크롤링 및 AI 요약기 (바탕화면 아이콘 클릭 시 로컬 브라우저로 대시보드 오픈)
  - 톱니바퀴 결함 검사기 (웹캠 연결 후 로컬에서 실시간 판정)
  - 사내 문서 RAG 검색기 (사내 PC에 FAISS + 로컬 LLM 탑재)

### 공식 2: 의뢰인 명의 클라우드 배포 (Client-Owned Cloud) — 추천도 ★★★★☆
- **방식**: 의뢰인(회사) 명의로 클라우드(Vercel, AWS, Cloudflare, Cafe24)에 가입하게 하고 거기에 배포
- **실무 진행 3단계**:
  1. 의뢰인에게 무료/저비용 티어 서비스(Vercel, Supabase, AWS 프리티어 등) 가입 링크 전달
  2. AnyDesk / TeamViewer 원격 접속으로 의뢰인이 보는 앞에서 결제 수단 등록 및 API 키 발급
  3. 개발자는 배포 스크립트로 의뢰인 계정에 배포 후 관리자 권한 완전 이양
- **결과**: **서버 비용은 의뢰인 법인 카드로 자동 청구**, 개발자에게 과금 리스크 0원

### 공식 3: 호스팅 대행 + 월 관리비 모델 (Retainer) — 추천도 ★★★★☆ (고수익화)
- **방식**: 개발자 명의의 고정 서버(AWS Lightsail 월 $5~$10 or Cafe24 월 5,500원)에 세팅하고, 의뢰인에게 월 5만~10만 원의 유지보수/서버비를 청구
- **장점**: 납품 10개만 쌓여도 매달 50만~100만 원의 패시브 인컴(고정 수입) 발생

## 2. 크몽 상세페이지 필수 항목: 심리학 기반 작성 문안

소비자는 **"내가 IT를 잘 모르는데 사기당하거나 말 안 통할까 봐"** 가장 두려워합니다.  
전문성과 안심(Psychological Safety)을 동시에 주는 문안입니다.

### (1) '서비스 제공 절차' 권장 문안 (크몽 등록용)

```
[서비스 제공 절차 (안심 5단계 파이프라인)]

1단계: 1:1 사전 기술 타당성 검토 (무료)
- 의뢰인의 요구사항과 준비된 데이터를 확인하고, AI 구현 가능 여부를 무료로 사전 진단해 드립니다.

2단계: 맞춤 견적 및 작업 범위 확정 (투명한 범위 설정)
- 요구사항에 딱 맞는 합리적인 일정과 견적을 합의하고, 추가금 없는 확정 작업 명세서를 작성합니다.

3단계: 핵심 기능 프로토타입 시연 (중간 점검)
- 작업 중간에 핵심 기능(크롤링 결과, AI 모델 분류 테스트, UI 화면)을 1차 공유하여 피드백을 반영합니다.

4단계: 최종 결과물 납품 및 1:1 원격 설치 지원
- 완성본 납품과 함께 비전공자도 즉시 사용 가능한 가이드 문서 및 1:1 원격 설치(AnyDesk)를 지원합니다.

5단계: 1개월 무상 사후 지원 (하자 보수)
- 납품 후 정상 작동하지 않거나 버그 발생 시 무상으로 즉시 수정해 드립니다.
```

### (2) '의뢰인 준비 사항' 권장 문안 (크몽 등록용)

```
[의뢰인 준비 사항 (비전공자도 3분 만에 준비 가능)]

복잡한 개발 명세서는 필요 없습니다! 아래 3가지만 편하게 알려주시면 됩니다:

1. 자동화/AI로 해결하고 싶은 일 (예: "매일 뉴스 100개를 요약해서 엑셀로 받고 싶어요")
2. 샘플 데이터 또는 참고 사이트 (예: 관련 파일 1~2개 or 벤치마크하고 싶은 웹사이트 링크)
3. 원하시는 최종 결과물 형태 (예: 엑셀 파일, 웹 화면, 슬랙/카카오톡 알림 등)

* 데이터가 정리되어 있지 않거나 무엇부터 준비해야 할지 모르시더라도 괜찮습니다.
  1:1 상담창에 말씀해 주시면 개발자가 직접 질문을 통해 명세를 구체화해 드립니다.
```

## 3. 의뢰인 요구명세서 수집 '5문 5답' 템플릿 (복사해서 상담창에 보낼 질문)

고객이 "이거 얼마예요?" 또는 "개발 가능한가요?"라고 문의했을 때, 바로 복사해서 보낼 **상담용 5문 5답 설문지**입니다.

```
안녕하세요, 고객님! 인공지능SW 수석 개발자 박준형입니다.
정확하고 거품 없는 맞춤 견적 및 일정 산출을 위해, 아래 5가지만 편하게 복사하여 작성해 주시면 감사하겠습니다. (모르시는 항목은 비워두셔도 됩니다!)

--------------------------------------------------
[맞춤 개발 요구사항 확인표]

1. 프로젝트 목적: (어떤 업무를 자동화하거나 어떤 문제를 해결하고 싶으신가요?)
   → 

2. 입력 데이터: (AI가 읽어야 할 데이터는 무엇인가요? 예: 뉴스 웹사이트 링크, PDF 문서, 사진 이미지 등)
   → 

3. 최종 출력물 형태: (결과물을 어떤 형태로 받고 싶으신가요? 예: 엑셀 다운로드, 웹 화면 대시보드, 슬랙 알림 등)
   → 

4. 사용 환경: (누가, 어디서 사용할 프로그램인가요? 예: 내 사무실 PC에서만 혼자 사용, 직원 5명이 웹에서 동시 접속 등)
   → 

5. 희망 마감일 및 예산 범위: (대략적으로 생각하시는 일정과 예산이 있으신가요?)
   → 
--------------------------------------------------

작성해 주시면 10분 내로 구현 가능 여부와 가장 저렴하고 효율적인 방식을 제안해 드리겠습니다!
```

## 4. 첫 시작으로 가장 추천하는 2대 진입 서비스

| 순위 | 추천 서비스명 | 권장 시작가 | 납품 형태 (인프라 고민 제로) |
| :---: | :--- | :---: | :--- |
| **1위** | **[맞춤형 빅데이터] 실시간 웹 크롤링 & AI 기사/리뷰 자동 요약 대시보드** | 19만 ~ 149만 원 | **PC 로컬 실행 파일(.exe) or 엑셀 자동화** (서버 비용 $0) |
| **2위** | **[기업 맞춤형] 사내 문서/PDF 기반 고정밀 RAG 챗봇 및 검색 엔진** | 29만 ~ 189만 원 | **로컬 브라우저 UI or 클라이언트 Vercel/Supabase 배포** |

- **선정 이유**: 
  1. 박준형 개발자의 기존 포트폴리오(국방 기사 파이프라인, CookDuck RAG)를 90% 이상 그대로 재사용 가능
  2. 고객이 서버를 몰라도 로컬 PC에서 즉시 실행 가능해 인프라 분쟁 리스크 0%
  3. 명세서가 단순 명료하여 클레임 발생 확률 최저
