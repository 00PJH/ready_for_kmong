- **작명 패턴**: `[기술/분야 키워드] + 핵심 기능/해결 과제 + 맞춤 제작/개발`. 특정 단일 프로젝트명 대신 기업 고객이 검색할 포괄적 도메인을 타이틀로 채택함.

  - 수정 횟수: 1회 (간이 프롬프트 조정 수준).
  - 제공 범위: FAQ 30건 내외 또는 기본 ChatGPT 프롬프트 세팅, 웹 UI 테스트 링크 제공.

  - 제공 범위: 사내 문서(PDF/DOCX) RAG 벡터화 + 출처 표기 기능 + 웹 위젯 또는 카카오톡 채널 연동 + 관리자 문서 업로드 UI.
- **PREMIUM (기업 맞춤 / 고단가)**:

  - 작업 일수: 15일 ~ 30일.

#### 3. 서비스 제공 절차 패턴
```text
1단계: 1:1 사전 상담 (목적, 문서 분량, 탑재 위치 확인)
2단계: 견적 확정 및 크몽 안전 결제
3단계: 코어 RAG 엔진 개발 및 데이터 임베딩
4단계: 테스트 링크 시연 (의뢰인이 직접 질문하며 답변 정확도 검수)
5단계: 카카오톡 채널 / 웹사이트 최종 배포 및 관리자 가이드 전달
6단계: 사후 하자보수 및 운영 안내
```
- **설계 이유**: AI 챗봇 특성상 '원하던 답변이 안 나온다'는 분쟁이 잦으므로, 최종 납품 전 **'테스트 링크 시연(중간 검수)'**을 반드시 배치하여 답변 품질 합의를 완료함.

#### 4. 의뢰인 준비 사항 패턴
1. 챗봇 학습용 문서 데이터 (FAQ 엑셀, 매뉴얼 PDF, 회사 소개서 등)
2. 챗봇 연동 대상 플랫폼 계정 (카카오 비즈니스 채널 계정 관리자 권한 또는 웹사이트 관리자 권한)
3. OpenAI API Key (의뢰인 본인 카드 등록 계정)
4. 테스트용 대표 질문 및 정답 예시 5~10세트
- **설계 이유**: API 종량제 비용을 의뢰인에게 귀속시켜 판매자의 유지비용을 0원화하고, 플랫폼 계정 소유권을 의뢰인이 갖게 하여 계정 제재 시 책임 소재를 분리함.

#### 1. 제목 구조 분석
- **업무 목적 명시**: `웹 크롤링`, `자동포스팅`, `이웃관리`, `자동화 솔루션`, `데이터 수집` 등 고객이 수작업으로 겪는 반복 노동 키워드를 정면에 배치.

#### 2. 패키지 구조 및 가격/일수/수정 횟수 실측 분석
- **저단가 반복형 (2만~3만 원)**: 단순 매크로/작업 보조 툴로 리뷰 50~70건을 빠르게 누적하는 전술.
- **맞춤형 개발형 (10만~100만 원)**:
  - STANDARD (99,000원 ~ 190,000원 / 작업 2~3일 / 수정 1회): 단일 사이트 크롤러, 정형 엑셀 저장.

#### 3. 서비스 제공 절차 패턴
```text
1단계: 수집 대상 사이트 URL 및 필요 데이터 필드 상담
2단계: 크롤링 기술적 가능성(차단 로직 유무) 검토 및 결제
3단계: 수집 샘플 엑셀 파일 1차 전달 (누락 데이터 확인)
4단계: 단독 실행 파일(.exe) 빌드 및 가이드 전달
5단계: 1:1 원격 접속(AnyDesk) 설치 지원 및 구동 검증
6단계: 하자 보수 지원
```

- **설계 이유**: 크롤러는 대상 웹사이트의 UI 변경 시 작동이 멈출 수 있으므로, 납품 시점에 샘플 데이터를 먼저 확인시키고, 파이썬 환경이 없는 일반인을 위해 **`.exe` 실행 파일과 원격 설치**를 제공하여 구동 오류 클레임을 차단함.

#### 4. 의뢰인 준비 사항 패턴
1. 수집 대상 웹사이트 주소(URL) 및 수집 주기
2. 엑셀에 저장되어야 하는 세부 열(Column) 목록
3. 구동 PC 환경: Windows 10/11 사양 및 Chrome 브라우저 설치 여부
4. 타깃 사이트 로그인 계정 (로그인 후 수집이 필요한 경우)
- **설계 이유**: macOS 호환성 이슈 및 버전 불일치를 방지하기 위해 구동 OS를 Windows로 명시하고, 비정상적 다량 호출에 따른 IP 차단 리스크를 사전에 고지함.

#### Q1. "원래도 Streamlit 무료 서버 링크 하나만 카톡으로 주나요?"
- **현실**: **STANDARD(검증/PoC) 또는 사내 내부 관리자용**으로는 매우 흔하게 씁니다.
  - **장점**: 파이썬 코드만으로 UI가 즉시 생성되며, GitHub 연결 시 무료 서빙(`https://xxx.streamlit.app`)과 HTTPS가 자동 제공됩니다.
  - **단점**: 모바일 UI가 다소 투박하고, 타사 홈페이지 안에 버튼/위젯 형태로 삽입하기 어렵습니다. 따라서 일반 고객 대상(B2C) 쇼핑몰/병원 챗봇으로는 쓰지 않습니다.

#### Q2. "Vercel 배포는 언제 어떻게 쓰나요?"
- **현실**: **대고객용 완성형 웹 챗봇**을 만들 때 업계 표준입니다.
  - **구조**: `Next.js` 프론트엔드를 Vercel(무료 Hobby 플랜)에 배포하고, 도메인(예: `bot.clientcompany.com`)을 연결합니다.
  - **장점**: 모바일 반응형이 뛰어나고, 로딩이 극도로 빠르며, CSS 커스텀 디자인이 자유롭습니다.

#### Q3. "홈페이지 위젯(Widget)은 어떻게 납품하나요?"
- **현실**: 크몽 구매자(쇼핑몰, 중소기업 대표)가 가장 선호하는 방식입니다.
  - 개발자가 Vercel에 위젯 스크립트(`widget.js`)를 올려두고, 의뢰인에게 아래 코드 한 줄을 줍니다:
    ```html
    <script src="https://my-chat-widget.vercel.app/bundle.js" data-bot-id="client-01"></script>
    ```
  - 의뢰인이 자기 웹사이트(카페24, 아임웹, 워드프레스) 설정 관리자에서 위 코드를 붙여넣으면, 홈페이지 우측 하단에 동그란 챗봇 아이콘이 뜨며 대화창이 열립니다.

#### Q4. "카카오톡 연동은 어떻게 납품하나요?"
- **현실**: 크몽 챗봇 주문 중 거래량이 가장 많은 방식입니다.
  - 카카오 비즈니스 계정에서 '카카오 i 오픈빌더'를 엽니다.
  - 개발자가 만든 백엔드 API(Render 무료 서버 또는 의뢰인 AWS Lightsail)의 Webhook URL을 카카오 스킬로 등록합니다.
  - 의뢰인은 자기 카카오톡 채널에 관리자 권한만 주면 되며, 최종 사용자는 카톡 플러스친구 채팅방에서 대화합니다.
