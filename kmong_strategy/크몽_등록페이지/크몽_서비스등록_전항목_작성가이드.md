# 크몽 AI 3대 서비스 등록 전항목 입력 데이터 종합 가이드

> **문서 목적**: 크몽 서비스 등록 화면(스크린샷 7종 분석 기준)의 필수 및 선택 입력 필드를 정리하고, 3개 서비스(맞춤형 챗봇, AI 자동화, 비전·음성 인식)에 대해 크몽 등록 페이지에 그대로 적용할 수 있는 1:1 맞춤형 입력 데이터를 제공합니다.  
> **저장 위치**: `kmong_strategy/크몽_등록페이지/크몽_서비스등록_전항목_작성가이드.md`

## 크몽 등록 시스템 필수 규격 및 주의사항

1. **서비스 제목 규격**: 최소 10자 이상 ~ 최대 30자 이하. **허용 특수문자는 `: + - # / . ( )` 만 가능** (가운뎃점 `·`, 쉼표 `,`, `<`, `>` 등 사용 불가).
2. **서비스 설명 / 절차 / 준비사항**: **특수문자 `<` 및 백틱 사용 불가** (크몽 에디터 오류 방지).
3. **패키지 입력 규격**:
   - 패키지 제목: 최대 20자 이내
   - 패키지 설명: 최대 60자 이내
4. **검색 키워드**: 최대 5개, 각 20자 이내.
5. **주요 특징 항목 정의 안내**:
   - **상주 여부**: 고객사 사무실로 직접 출근하여 작업하는지 여부를 뜻합니다. (상주: 고객사 사무실 출근 / 비상주: 재택 및 원격 작업). 프리랜서 외주 개발 서비스는 **`비상주`**를 선택합니다. 고객과의 소통은 메신저, 원격 접속, 유선 등으로 원활하게 이루어집니다.
   - **활용 목적**: 체크박스 형태의 다중 선택이 가능합니다. 해당 서비스에서 제공 가능한 영역을 복수 선택합니다.
