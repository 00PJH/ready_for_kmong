### (4) 서비스 설명 (복사-붙여넣기용, 특수문자 `<` 및 백틱 미사용)
```text
[매일 반복되는 고객 문의에 지치셨나요?]
[사내 규정집, 매뉴얼을 찾아 헤매는 시간을 줄이고 싶으신가요?]

단순한 룰 기반 챗봇이 아닌, 고객사의 실제 문서(PDF, Excel, Word)를 학습하고 정확한 출처까지 표기하는 똑똑한 AI 챗봇을 구축해 드립니다.

인공지능 소프트웨어 전공 수석 졸업 엔지니어가 직접 설계하여, 거짓 답변(할루시네이션) 없는 안정적인 맞춤형 챗봇을 약속드립니다.


■ 이런 분들께 강력히 추천합니다!
1. 쇼핑몰, 병원, 학원 등 24시간 반복 CS 상담을 자동화하고 싶으신 대표님
2. 사내 취업규칙, 제품 매뉴얼, 기술 문서를 빠르게 검색해야 하는 기업 임직원
3. 웹사이트 우측 하단에 코드 한 줄로 깔끔한 챗봇 위젯을 띄우고 싶으신 분
4. 고객 접근성이 가장 좋은 카카오톡 채널에 챗봇을 연결하고 싶으신 분


■ 본 서비스만의 핵심 차별점 3가지

1. 100% 출처 표기로 거짓 없는 답변 (RAG 지식 검색 기술)
챗봇이 아무 말이나 지어내지 않습니다. 등록해주신 문서 내에서만 답변하며, "어느 문서, 몇 페이지를 참고했는지" 출처를 명확히 제시합니다.

2. 편리한 연동 방식 (카카오톡 또는 웹사이트 1줄 코드)
- 카카오톡 채널 연동: 24시간 고객 카카오톡 채팅방에서 즉시 자동 상담.
- 홈페이지 위젯 연동: 제공해드리는 스크립트 코드 1줄만 붙여넣으면 홈페이지 우측 하단에 챗봇 아이콘이 생성됩니다.

3. 직관적인 관리자 페이지 제공
새로운 매뉴얼이나 공지사항이 생기셨나요? 개발자를 다시 부를 필요 없이, 관리자 화면에서 파일만 업로드하시면 챗봇이 즉시 새로운 지식을 학습합니다.


■ 패키지별 상세 안내

- 기본 AI API 연동 + FAQ 30건 프롬프트 맞춤 세팅 + 즉시 테스트 가능한 웹 링크 제공

- 사내 문서 100장+ RAG 임베딩 + 100% 출처 표기 + 카카오톡 채널 or 웹 위젯 연동 + 관리자 문서 관리 UI
```

```text
[매일 반복되는 웹사이트 복사, 붙여넣기, 언제까지 손으로 하시겠습니까?]

4. 복잡한 파이썬 설치 없이, 그냥 더블클릭만 하면 실행되는 깔끔한 윈도우 프로그램을 원하시는 분


■ 본 서비스만의 핵심 차별점 3가지

1. 단순 수집을 넘어선 AI 텍스트 자동 가공
데이터만 긁어모은다고 끝이 아닙니다. ChatGPT 및 AI 요약 모델을 결합하여, 수집된 긴 본문을 핵심 3줄로 자동 요약하거나 카테고리별로 자동 분류하여 엑셀에 채워드립니다.
```
