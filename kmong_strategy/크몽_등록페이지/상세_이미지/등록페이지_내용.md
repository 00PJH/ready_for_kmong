### [서비스 소개]

사내 문서 검색과 반복적인 고객 응대 시간을 줄여주는 맞춤형 AI 챗봇을 제공합니다.

인공지능소프트웨어학과를 수석 졸업(크몽 공식 학력 인증 완료)하고 정보처리기사 자격을 보유한 개발자가 데이터 전처리부터 검색 알고리즘 설계, 채널 연동까지 직접 수행합니다.

단순히 API만 연결하는 방식이 아니라, 고객사에서 전달해주신 실제 문서(PDF, Excel, Word 등)를 기반으로 답변하고 참고한 문서명과 페이지를 함께 표시하는 지식 기반(RAG) 시스템을 구축합니다.

### [추천 대상]

1. **24시간 고객 상담(CS) 자동화가 필요한 사업자**

- 쇼핑몰, 병원, 학원, 서비스업 등에서 자주 묻는 질문(환불 규정, 예약 및 이용 안내, 상품 정보)을 카카오톡 채널이나 웹사이트에서 자동 응대하고자 하는 분

2. **사내 규정 및 업무 매뉴얼 검색 효율을 높이고 싶은 기업**

- 취업규칙, 인사/회계 규정, 기술 매뉴얼, 제품 규격서를 일일이 찾는 대신 채팅을 통해 근거 페이지와 답변을 빠르게 확인하고 싶은 실무진

3. **데이터 보안이 요구되는 기업 및 기관**

- 사내 기밀 및 고객 데이터가 외부 AI 학습에 활용되지 않는 기업용 보안 API(데이터 비학습 및 보안 정책) 환경이 필요한 곳

### [핵심 기술 및 제공 특징]

1. **가중치 기반 하이브리드 검색(RAG) 및 출처 표기**

- 문맥 의미를 파악하는 벡터 검색과 조항 번호·고유명사를 식별하는 키워드 매칭을 가중치로 결합해 구축합니다.
- 일반적인 벡터 검색에서 자주 발생하는 조항 번호나 규정 수치 혼선 문제를 보완하여, 일상적인 대화체 질문("연차 신청 기한")과 문서상의 공식 규정("취업규칙 제15조")을 알맞게 대응시킵니다.
- 답변 시 근거가 된 원본 문서명과 페이지 번호를 함께 명시하고, 문서에 포함되지 않은 내용은 임의로 답하지 않도록 지침을 지정합니다.

2. **비동기 스트리밍 및 응답 속도 최적화**

- 비동기 추론 서버(FastAPI 및 WebSockets) 구조를 적용하여 대기 시간을 줄이고, 답변이 실시간으로 타이핑되는 스트리밍 환경을 제공합니다.

3. **카카오톡 비즈니스 채널 및 웹사이트 위젯 연동**

- **웹사이트 위젯**: 전달해 드리는 스크립트 코드 1줄을 홈페이지에 삽입하여 우측 하단에 챗봇 창을 띄울 수 있습니다.
- **카카오톡 채널**: 카카오톡 비즈니스 채널 채팅방에 AI 엔진을 연동하여 별도 앱 설치 없이 상담이 가능합니다.
- **모바일 및 PC 호환**: 스마트폰과 PC 웹 브라우저 화면 비율에 맞춰 반응형으로 동작합니다.

4. **문서 관리용 관리자 화면 제공 (DELUXE 이상)**

- 새로운 규정이나 공지사항 파일이 추가될 때 담당자가 직접 웹 화면에서 PDF, 엑셀, 워드 파일을 업로드하여 챗봇 지식을 갱신할 수 있습니다.

2. **DELUXE : 하이브리드 RAG + 채널 연동 + 관리자 UI (390,000원 / 작업 7일 / 수정 2회)**

- 웹사이트 우측 하단 위젯 또는 카카오톡 비즈니스 채널(디스코드, 텔레그램 타 메신저 협의 가능) 연동 중 택1

- 납품 후 7일 무상 유지보수 지원
- _추천: 실제 사내 문서와 매뉴얼을 학습시켜 고객 상담이나 사내 업무에 즉시 투입할 완성형 챗봇이 필요한 기업_

3. **PREMIUM : 기업 보안 AI + 시스템 연동 (990,000원 / 작업 14일 / 수정 3회)**

- 대용량 사내 문서(500페이지 이상) 심층 RAG 구축
- 사내 데이터베이스(MariaDB, MySQL, 외부 REST API) 연동을 통한 실시간 데이터 조회
- 외부 AI 학습에서 배제되는 기업용 보안 API 연동으로 데이터 유출 방지
- 맞춤형 관리자 대시보드 UI 제공
- 납품 후 30일 무상 유지보수 지원
- _관리자 페이지나 채널 연동 없이 기본 웹 화면에 문서 학습(RAG) 기능만 적용하거나, 문서 분량이 패키지 기준과 다른 경우 문의주시면 작업 범위에 맞춰 합리적인 중간 견적으로 안내해 드립니다._

> 도입 목적과 보유하신 문서 형태를 메시지로 남겨주시면 확인 후 구체적인 구축 방향과 견적을 안내해 드리겠습니다.

## 4. 서비스 제공 절차

1. **사전 상담 및 요구사항 검토**

- 챗봇 도입 목적과 보유하신 데이터(FAQ 리스트 또는 PDF, 엑셀, 매뉴얼 등)의 분량을 확인하고 적합한 구축 방식을 안내합니다. 결제 전 샘플 데이터 기반으로 문서의 '학습 적합성 사전 검토'를 무료로 진행해 드립니다.

2. **작업 범위 확정 및 안전 결제**

- 연동할 채널(독립 웹 화면, 웹사이트 위젯, 카카오톡 채널)과 세부 일정을 합의한 뒤 크몽 안전 결제를 진행합니다.

3. **데이터 전처리 및 챗봇 엔진 개발**

- 패키지에 맞춰 맞춤형 프롬프트 설계 또는 문서를 의미 단위로 분할하는 하이브리드 RAG 검색 파이프라인을 구축합니다.

4. **테스트 링크 시연 (중간 점검)**

- 최종 반영 전, 실제 대표 질문을 입력하여 답변 정확도와 출처 표기 상태를 확인하실 수 있는 테스트 링크를 제공합니다.

5. **최종 채널 연동 및 운영 가이드 전달**

- 피드백을 반영하여 답변 톤앤매너와 정확도를 조율한 뒤, 지정된 채널에 최종 연동을 완료하고 한글 운영 매뉴얼을 전달합니다.

6. **사후 유지보수 지원**

- 납품 후 각 패키지 기준(STANDARD/DELUXE 7일, PREMIUM 30일)에 따라 무상 수정을 지원합니다.

- _예시 1 : "단순 변심으로 환불이 가능한가요?" → "수령 후 7일 이내 미개봉 시 왕복 배송비 부담 후 가능"_
- _예시 2 : "연차 휴가 신청은 언제까지 해야 하나요?" → "사용 희망일 최소 3일 전까지 그룹웨어 결재 완료"_

- 의뢰인 계정의 API Key _(OpenAI ChatGPT, Google Gemini, Anthropic Claude 중 희망 모델 선택 가능 / 발급 가이드 지원)_

### [2. 답변 완성도 향상을 위한 추가 선택 항목 (권장)]

- **1) 원하는 페르소나 및 톤앤매너**
- 희망하시는 AI의 캐릭터와 말투를 알려주세요. _(예 : "친절하고 정중한 전문 상담원 말투", "격식 있고 정확한 기술 엔지니어 어조", "부드러운 대화체" 등)_

- **2) 예외 상황 안내 지침**
- 문서에 없는 질문이나 답변하기 곤란한 문의가 들어왔을 때의 대응 방식을 지정해 주세요. _(예 : "사내 규정에 없는 내용은 지어내지 말고 인사팀 담당 부서로 문의하도록 안내", "고객센터 운영시간 안내 문구 출력" 등)_

- **3) 참고 레퍼런스**
- 벤치마킹하고 싶은 타사 챗봇 서비스나 웹사이트가 있다면 알려주세요. 대화 흐름 설계에 적극 반영해 드립니다.

### [3. RAG 학습 문서 전달 시 주의사항 (필독)]

- RAG 지식 기반 챗봇의 답변 정확도는 제공해주시는 원본 텍스트 품질에 직접적인 영향을 받습니다.
- 글자를 드래그할 수 없는 스캔 이미지 형태의 PDF나 복잡한 다중 병합 표는 AI 인식률이 떨어질 수 있으므로, 가급적 텍스트로 정리된 문서 파일(Word, Excel, 일반 텍스트 PDF) 형태로 전달해 주시면 가장 높은 답변 품질을 얻으실 수 있습니다.
- 사내 기밀 및 개인정보는 마스킹(가림 처리) 후 전달해 주시는 것을 권장하며, 전달해주신 모든 데이터는 개발 완료 후 즉시 안전하게 파기됩니다.

## 2. 수정 및 재진행 안내

### [수정 작업 가능 범위 및 기준]

1. **수정 가능 시점 및 횟수**

- **시점**: 1차 결과물(테스트 링크) 전달 후 구매 확정 전 검수 단계에서 진행됩니다.
- **횟수**: 각 패키지 기본 제공 횟수(STANDARD 1회, DELUXE 2회, PREMIUM 3회) 내에서 진행됩니다.

2. **무상 수정에 포함되는 범위 (경미한 수정)**

- **프롬프트 페르소나 미세 조정**: 챗봇의 말투, 응대 톤앤매너, 존댓말/반말 설정, 인사말 및 예외 안내 문구 변경
- **데이터 일부 수정**: 기존 학습된 문서 내의 단순 오타, 텍스트 일부(기존 분량의 20% 이내) 갱신
- **UI 요소 조정**: 웹 위젯 색상, 로고 이미지, 버튼 명칭 등 디자인 설정값 변경

3. **추가 개발(유상 재진행)로 분류되는 경우**

- 사전 협의된 기획 외 새로운 기능 추가 _(예 : 외부 DB 연동, 신규 채널 추가 연동, 결제/예약 연동 등)_
- 학습 데이터의 전면적인 교체 _(기존 전달 문서의 50% 이상 변경 또는 대량의 신규 문서 추가)_
- 납품 및 구매 확정 완료 후 새로운 요구사항에 따른 변경 요청
- _추가 개발 건은 작업 공수에 따라 상호 협의 후 추가 결제(맞춤 견적)를 통해 진행됩니다._

4. **전문가 귀책사유로 인한 오류 지원**

- 개발 과정에서 발생한 시스템 오류, 링크 접속 불가 등 기술적 결함은 수정 횟수 차감 없이 무상 조치합니다.

## 2. 자주 묻는 질문 (현재 크몽 등록 19개 일치본)

- **Q1. PDF 파일을 AI 모델 자체에 파인튜닝(재학습)시키는 방식인가요?**
  → 모델 자체를 재학습시키는 방식이 아닙니다. 질문이 들어왔을 때 사내 문서에서 관련된 핵심 문단을 검색해 AI 모델에게 근거로 제공한 뒤 정답을 생성하게 만드는 최신 검색 증강 생성(RAG) 기술을 적용합니다. 이를 통해 모델 재학습 비용 없이도 문서를 실시간으로 반영할 수 있습니다.
- **Q2. 챗봇이 문서에 없는 거짓 정보(환각 현상)를 사실처럼 꾸며내지 않나요?**
  → 임의 생성 방지 프롬프트 가드레일을 철저히 적용합니다. 특히 DELUXE 이상 패키지에서는 답변의 근거가 된 문서명과 페이지를 함께 표기하며, 전달해주신 문서 데이터 내에 언급되지 않은 질문에 대해서는 지어내지 않고 정중한 예외 안내 문구를 출력하도록 제어합니다.
- **Q3. OpenAI의 ChatGPT 모델만 연결 가능한가요?**
  → Gemini, Claude 등 다양한 최신 모델을 비용 및 속도 요구조건에 맞춰 선택하여 연동할 수 있습니다.
- **Q4. 이미 운영 중인 자사 홈페이지나 쇼핑몰에 바로 붙일 수 있나요?**
  → 가능합니다. DELUXE 이상 패키지 선택 시 전달해 드리는 웹 위젯 스크립트 코드 1줄을 홈페이지 HTML에 삽입하시면 우측 하단 팝업 챗봇 형태로 즉시 연동됩니다. (STANDARD는 단독 웹 채팅 링크 형태로 제공됩니다.)
- **Q5. 글자 드래그가 안 되는 스캔된 이미지 PDF 문서도 인식하나요?**
  → 텍스트 문서는 안정적으로 인식되며, 스캔본은 사전 샘플 검토를 통해 OCR 전처리 가능 여부를 안내해 드립니다.
- **Q6. 추후 사내 규정이나 제품 문서가 계속 늘어나면 어떻게 업데이트하나요?**
  → DELUXE 이상 패키지에서 제공되는 관리자 UI를 통해 담당자가 직접 파일을 추가·삭제할 수 있습니다.
- **Q7. 납품 시 개발된 전체 소스코드도 함께 전달받을 수 있나요?**
  → DELUXE 및 PREMIUM 패키지는 원본 소스코드를 기본 제공하여, 고객사의 독립적인 IT 자산으로 운영하실 수 있습니다.
- **Q8. 여러 사람이 동시에 챗봇에 접속해서 질문해도 속도가 느려지지 않나요?**
  → 비동기 추론 서버 구조를 채택하여 동시 접속 시에도 병목 없이 빠른 스트리밍 답변을 제공합니다.
- **Q9. 어떤 포맷의 문서 데이터를 전달해야 학습이 가능한가요?**
  → PDF, Word, Excel, CSV, TXT 등 텍스트 기반의 거의 모든 표준 문서 파일 포맷을 지원합니다.
- **Q10. 직원들이 사내 규정이나 업무 매뉴얼을 찾아보는 용도로 쓸 수 있나요?**
  → 네, 가능합니다. 취업규칙, 총무/인사 매뉴얼, 기술 규격서 검색에 최적화되어 질문 시 해당 조항과 근거 페이지를 빠르게 안내합니다.
- **Q11. 정리된 매뉴얼이나 FAQ 문서가 없는데 챗봇 제작이 불가능한가요?**
  → 가능합니다. 기존 상담 내역이나 회사 소개서 등 보유하신 기초 자료를 바탕으로 상담을 통해 Q&A를 함께 정리해 드립니다.
- **Q12. 카카오톡 연동 시 필요한 사전 준비물은 무엇인가요?**
  → 카카오 비즈니스 채널 관리자 계정이 필요합니다.
- **Q13. 완성 후 챗봇을 오픈하고 나서 문제가 생기면 어떻게 대처해 주시나요?**
  → 납품 완료 후 각 패키지 기준(STANDARD/DELUXE 7일, PREMIUM 30일)에 따라 합의된 기능 범위 내의 오류 및 답변 뉘앙스를 집중 점검해 드립니다.
- **Q14. 관리자 화면에서는 문서 업로드 외에 어떤 설정이 가능한가요?**
  → 문서 추가·삭제 외에도 챗봇의 인사말, 기본 시스템 지침 등의 설정값을 직관적으로 관리할 수 있습니다.
- **Q15. AI 답변 도중 상담원 연결이나 외부 문의 폼(URL)으로 전환할 수 있나요?**
  → 해결하기 어려운 질문 발생 시 대표 카카오톡 상담 채널이나 공식 문의 접수 창구로 안내하도록 설정합니다.
- **Q16. AI 모델의 API 키를 발급받아 본 적이 없는데 직접 해야 하나요?**
  → 가이드를 제공하여 비전공자도 5분 안에 안전하게 직접 발급받으실 수 있습니다.
- **Q17. 챗봇을 도입한 후 매월 판매자에게 지불해야 하는 고정 관리비가 있나요?**
  → 판매자에게 내는 고정 비용은 일체 없으며, 사용한 만큼만 AI 공급사(OpenAI 등)에 직접 결제됩니다.
- **Q18. 패키지 안내와 다른 세부 요구사항(문서 분량 조절 등)도 맞춤 제작되나요?**
  → 필요한 기능(문서 학습만, 채널 연동만 등)을 분리하여 작업 범위에 딱 맞춘 합리적 중간 견적을 드립니다.
- **Q19. 정식 결제 전에 우리 회사 문서로 답변 시연이나 테스트를 미리 받아볼 수 있나요?**
  → 결제 전 개별 사전 시연 및 맞춤 테스트는 지원하지 않으며, 대신 문서의 '학습 적합성 사전 검토'를 무료로 진행해 드립니다. 샘플 문서(1~2장)를 보내주시면 텍스트 파싱 가능 여부를 점검해 드립니다. 실제 질문·답변 테스트는 크몽 안전 결제 후 1차 개발 완료 단계에서 제공되는 테스트 링크를 통해 직접 확인하실 수 있습니다.
