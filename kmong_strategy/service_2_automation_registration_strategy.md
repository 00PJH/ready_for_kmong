## 4. 서비스 제공 절차 (단계별 프로세스 및 분쟁 방지 설계)

```text
1단계: 수집 대상 사이트 URL 및 필요 데이터 항목 사전 검토 (차단 로직 확인)
2단계: 견적 확정 및 크몽 안전 결제
3단계: 수집 및 AI 가공 샘플 엑셀 파일 전달 (중간 검수: 누락 필드 확인)
4단계: 단독 실행 프로그램(.exe) 패키징 및 가이드 전달
5단계: 1:1 원격 접속(AnyDesk) 설치 지원 및 정상 구동 검증
6단계: 1개월 무상 하자보수 지원
```

### [분쟁 방지 설계 이유]
- 크롤러 외주의 주요 클레임은 "제 컴퓨터에서 파이썬 에러가 떠요", "특정 데이터가 빠졌어요"입니다.
- 이를 막기 위해 **3단계에서 샘플 엑셀을 먼저 확인**시켜 필드 누락을 차단하고, 파이썬 환경 구축이 필요 없는 **더블클릭 실행 파일(`.exe`)과 원격 설치**를 제공하여 구동 오류 클레임을 원천 차단합니다.

## 5. 의뢰인 준비 사항 및 사전 고지

```text
1. 수집하고자 하는 타깃 웹사이트 주소(URL)
2. 엑셀에 저장되어야 하는 세부 항목 (예: 상품명, 가격, 작성일, 본문 텍스트 등)
3. 실행할 컴퓨터 환경: Windows 10/11 사양 및 Chrome 브라우저 설치
4. 타깃 사이트 로그인 계정 (로그인 후 접근해야 하는 데이터인 경우)
5. OpenAI API Key (AI 텍스트 가공이 들어가는 경우 / 원격 발급 지원)
```

### [책임 분리 설계 이유]
- macOS 호환성 문제를 사전에 차단하기 위해 지원 OS를 Windows로 한정합니다.
- 사이트 측의 과도한 트래픽 차단(IP Block)을 예방하기 위해 안전한 딜레이(Time Sleep)가 적용됨을 사전 고지합니다.

- **국방 뉴스 파이프라인 기술 자산 직결**:
  - **Selenium 동적 렌더링 극복**: 무한 스크롤, 버튼 클릭, 로그인 세션 유지 완벽 대응.
  - **텍스트 분류 & 요약 AI 탑재**: 수집된 본문을 읽고 klue/bert 분류 및 KoBART 3줄 요약 엔진으로 실무용 가공 데이터 산출.
  - **50건 단위 배치 OOM(메모리 초과) 방지**: 며칠 동안 쉬지 않고 돌아도 컴퓨터가 멈추지 않는 상용급 안정성 보장.
- **배포 인프라 현실화**:
  - 서버 비용 $0. 의뢰인의 Windows PC에서 더블클릭만으로 실행되는 **로컬 `.exe` 단독 파일**로 납품.

## 7. 크몽 등록용 완성형 상세페이지 본문 (복사-붙여넣기용)

```markdown
# ⚡ 웹 크롤링/데이터 수집 맞춤 AI 업무 자동화 개발

**"매일 반복되는 웹사이트 복사·붙여넣기, 언제까지 손으로 하시겠습니까?"**  
**"수집한 방대한 텍스트, 일일이 읽고 요약하느라 야근하고 계신가요?"**

단순한 데이터 수집을 넘어, **웹사이트 실시간 크롤링부터 AI 핵심 요약·분류·엑셀 자동 저장까지 한 번에 끝내는 업무 자동화 프로그램**을 맞춤 제작해 드립니다.

인공지능 소프트웨어 전공 수석 졸업 엔지니어가 직접 개발하여, 멈추지 않는 안정적인 프로그램을 더블클릭 한 번으로 실행하실 수 있게 만들어 드립니다.

### 📌 이런 분들께 강력히 추천합니다!

- 경쟁사 상품 가격, 재고, 리뷰 데이터를 매일 엑셀로 자동 정리하고 싶으신 이커머스 셀러
- 부동산 매물, 채용 공고, 입찰 정보 등 최신 업데이트를 실시간으로 모니터링해야 하는 담당자
- 쏟아지는 뉴스, 블로그, 커뮤니티 글을 자동으로 수집하고 AI 3줄 요약본으로 받아보고 싶으신 분
- 복잡한 파이썬 설치 없이, 그냥 더블클릭만 하면 실행되는 깔끔한 윈도우 프로그램을 원하시는 분

### 🚀 본 서비스만의 핵심 차별점 3가지

#### 1. 단순 수집을 넘어선 AI 텍스트 자동 가공
데이터만 긁어모은다고 끝이 아닙니다. ChatGPT 및 AI 요약 모델을 결합하여, **수집된 긴 본문을 핵심 3줄로 자동 요약하거나 카테고리별로 자동 분류**하여 엑셀에 채워드립니다.

#### 2. 파이썬 설치 불필요! 더블클릭 실행 파일(.exe) 납품
컴맹이어도 전혀 걱정하실 필요 없습니다. 복잡한 개발 환경 세팅 없이 **바탕화면에서 아이콘만 더블클릭하면 엑셀 파일이 자동으로 생성되는 단독 실행 프로그램**으로 납품합니다.

#### 3. 24시간 멈추지 않는 안정적인 메모리 제어
대량의 데이터를 수집하다가 프로그램이 멈추거나 튕기는 현상을 원천 차단합니다. 대용량 배치 처리 로직을 적용하여 며칠을 연속 구동해도 PC가 버벅거리지 않습니다.

### 🛠 서비스 진행 절차

1. **사전 문의 및 타깃 사이트 검토**: 수집을 원하시는 사이트 주소와 필요 항목을 확인하고 기술적 구현 가능 여부를 사전에 무료로 진단합니다.
2. **견적 확정 및 안전 결제**: 합의된 작업 범위에 맞춰 추가금 없는 크몽 안전결제를 진행합니다.
3. **샘플 데이터 1차 검수**: 실제 수집 및 AI 요약된 샘플 엑셀 데이터를 먼저 확인시켜 드립니다.
4. **프로그램 패키징 및 납품**: 파이썬 설치가 필요 없는 단독 실행 파일(.exe)로 빌드하여 전달합니다.
5. **1:1 원격 설치 지원**: 필요 시 AnyDesk 원격 접속으로 고객님 PC에서 정상 작동을 함께 검증합니다.
6. **사후 관리**: 납품 후 1개월간 발생하는 버그나 오류를 무상으로 수정해 드립니다.
```
